Put your portfolio PDFs in this folder using these exact filenames:

- resume.pdf
- general-education-reflection.pdf
- cumulative-reflection.pdf
- ethics-paper.pdf
- senior-design-document.pdf
- senior-design-presentation.pdf
- internship-evaluation.pdf      (if applicable)
- internship-presentation.pdf    (if applicable)

The Resume and Reflections pages embed these automatically. Until a file
exists, the page shows a striped placeholder telling you which file to add.
